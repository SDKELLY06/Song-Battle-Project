# Summer2026
Refreshing my skills and commiting to learn during the summer.

This repo includes a jupyter notebook in which you and a friend can input a song of choice and three machine learning algorithms will judge your songs based on spotify audio features and decice who chose the better song. 

You are required to choose between three of the seven following, to decide how the algorithms interpret which song is better.
1. Energy
2. Tempo
3. Danceability
4. Liveness
5. Valence
6. Speechiness
7. Loudness

Packages used for this repo:

-  Numpy

-  Sklearn
