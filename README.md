# General
This repo includes a jupyter notebook in which you and a friend can input a song of choice and three machine learning algorithms that will judge your songs like a scorecard based on spotify audio features and decice who chose the better song. 

The Models give each song a track popularity score, which already exists in the database as track_popularity. This is interesting to compare the actual spotify decision compared to the ones each of the models have made. 

# User Decisions
You are required to choose between three of the seven following, to decide how the algorithms interpret which song is better.
1. Energy
2. Tempo
3. Danceability
4. Liveness
5. Valence
6. Speechiness
7. Loudness
