# Summer2026
Refreshing my skills and commiting to learn during the summer.

This repo includes a jupyter notebook in which you and a friend can input a song of choice and three machine learning algorithms will judge your songs based on spotify audio features and decice who chose the better song. 

You are required to choose between three of the eight following, to decide how the algorithms interpret which song is better.
1. Energy
2. Tempo
3. Danceability
4. Liveness
5. Valence
6. Speachiness
7. Loudness
8. track popularity

Packages used for this repo:
-  Pandas
-  Numpy


The following tools were used:
-  Visual Studio Code 
-  GitHub

Constrains:
-  Spotify has 250 million songs, so this only highlights 1686 songs. These are high popularity songs according to spotify.
